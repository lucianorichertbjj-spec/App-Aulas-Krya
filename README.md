# Krya BJJ — Portal & Gestão da Academia

Projeto pronto para subir no **GitHub + Vercel** e conectar ao **Firebase Firestore** direto pelo navegador do celular.

## Como colocar no ar (passo a passo rápido):
1. Crie um projeto gratuito em **console.firebase.google.com** e ative **Firestore Database** e **Authentication (Anônimo)**.
2. Copie o `firebaseConfig` nas configurações do projeto Firebase e cole dentro do arquivo `src/firebaseConfig.js`.
3. Crie um repositório no **github.com**, envie os arquivos desta pasta e importe o repositório na **vercel.com** para ganhar seu link oficial.
